# Job Portal

A simple Job Portal web application built with **Laravel**. The project uses Laravel for backend functionality and **Blade templates** for the frontend.

## 🛠️ Technologies Used

* PHP
* Laravel
* MySQL
* Blade
* HTML, CSS & JavaScript

## ⚙️ Installation

Clone the repository:

```bash id="j3w6m9"
git clone https://github.com/surindermeena/job-portal.git
```

Go to the project directory:

```bash id="0qh7eu"
cd job-portal
```

Install dependencies:

```bash id="2vjkgy"
composer install
```

Create the environment file:

```bash id="y1w4jk"
cp .env.example .env
```

Generate the application key:

```bash id="glxg7e"
php artisan key:generate
```

Configure your database in the `.env` file and run:

```bash id="jhw1xg"
php artisan migrate
```

Start the development server:

```bash id="ek8n2m"
php artisan serve
```

Open the application in your browser:

```text id="0sjivq"
http://127.0.0.1:8000
```
